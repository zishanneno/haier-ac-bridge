GOOD TO KNOW

Keep it close to home.

The bridge and ACs need to be on the same home network. After setup, normal controls go directly to each AC.

Discovery can be blocked by Docker or guest Wi-Fi. You can enter an AC's IP address below or next to an account device.

Apple-only sign-in requires a Haismart account password. hOn and SmartAir2 devices are not supported by this bridge.

Add by IP or local key

Use this if discovery misses an AC, or if you already have its local key.
